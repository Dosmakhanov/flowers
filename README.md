# Цветикибукетики

Небольшой проект цветочного магазина с акцентом на аккуратный UI и поведение интерфейса.
Проект сделан без фреймворков, на чистом HTML, CSS и JavaScript, чтобы разобраться в базе фронтенда и работе браузера.

## 🔗 Страницы

- **Главная** — презентация магазина, hero-блок, подборка букетов
- **Каталог** — список букетов с фильтрацией по категориям
- **Контакты** — базовая контактная информация

## 🛠 Используемые технологии

- **HTML5** — семантическая структура страниц
- **CSS3**
  - Flexbox
  - адаптивные отступы
  - hover-состояния
  - анимации появления элементов
- **Vanilla JavaScript**
  - фильтрация товаров
  - управление состояниями интерфейса
  - работа с DOM без библиотек

## ⚙️ Функциональность

- фильтрация товаров по категориям
- плавное появление карточек при переключении фильтров
- единый хэдер и навигация между страницами
- аккуратная, чистая верстка без лишнего кода
